# Karthikeya Hospitals

Responsive React + Vite website inspired by the supplied reference image.

## Run locally
1. Install Node.js LTS.
2. Open this folder in VS Code or Antigravity.
3. Run `npm install`
4. Run `npm run dev`
5. Open the localhost URL printed in the terminal.

## Production build
Run `npm run build`.

## Before publishing
- Replace placeholder address, phone, email, hours and map location with verified hospital details.
- Confirm all departments, facilities, doctors and claims.
- Doctor profiles and images are illustrative placeholders, not verified hospital staff/photos.
- Appointment form validates input locally only; it does not send or confirm appointments until connected to a backend/API.
